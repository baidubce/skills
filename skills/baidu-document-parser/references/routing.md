# 选路与场景参数速查

本文件是 SKILL.md 第 2、3 节的详表备份，供需要时展开查阅。**选路以 Skill 为准，Agent 不要自己猜；用户点名引擎时以用户为准。**

## 选引擎（文件 × 场景）

### 标准版 4.0（`--engine standard`）

只要 Markdown（可顺带目录）：

- 流式文档：doc / docx / wps / txt / xls / xlsx / ppt / pptx 等。
- 可编辑、可选中复制的 PDF，且这轮**不需要**框位置、行坐标、印章、单元格点选。
- 只要把正文读清楚，去做摘要、条款问答、对比文字差异。
- 简单合同、标书（扫描件、带章、要核对位置）也可以用标准版。
- 格式覆盖全、标题和表结构稳，长 PDF 页数上限更高（约 2000 页，以官方为准）。
- **不要把 Word 丢给 VL。**

### PaddleOCR-VL 1.6（`--engine vlm`）

- 图片：jpg / png / bmp / tif / 拍照件、截图。
- 扫描 PDF、不能选中文字的 PDF。
- 教育（公式多）、论文、报刊杂志、复杂图文混排。
- 需要版面框、行坐标、单元格、印章、图表解读。
- 数字 Word / 可复制 PDF 且只要正文时，仍走标准版。

## 场景 × 参数（参数是默认，不是每次手填；用户要再开）

| 场景 | 引擎 | 建议打开 | 不要默认开 |
|------|------|---------|-----------|
| Word / Excel / 可复制 PDF，只要读正文 | 标准版 | Markdown；有章节则目录 | 行坐标、印章 |
| 可复制 PDF，但下游要点回原件 | 标准版 | 目录 + 版面块 | VL |
| 扫描合同 / 标书 | VL | 标题分级、合表、识章 | 擦章（会改画面） |
| 单页图片、证件、发票照片 | VL | 角度矫正 | — |
| 跨页合表 | VL | merge_tables | — |
| 论文、课件、试卷（公式多） | VL | 公式（默认有）、标题分级 | — |
| 报刊、杂志、海报 | VL | 图、阅读顺序 | 把页眉页脚当正文 |
| 年报里的柱状/折线统计图 | VL | analysis_chart | 普通照片图 |
| 跨页费用表、合并报表 | VL | merge_tables | — |
| 出版校对、原文高亮到行 | VL | return_span_boxes | 把行框塞进对话 |
| 斜拍、颠倒扫描件 | VL | 角度矫正；弯折再 unwarp | — |
| 章或水印挡住字，只要读字 | VL | 按需 erase_seal / erase_watermark | 还要核章时不要擦 |
| 多语种（日韩拉丁等） | VL | 模型默认识别即可 | 标准版硬填错语种 |
| Excel 多 Sheet | 标准版 | 按 sheet 名当目录 | 当成长 PDF |
| 超长数字标书、只要按章抽 | 标准版 | 目录，先不要全书（--page_range） | 整本丢给 VL |

## 不降级（硬约束）

1. 多页文档一律用本 Skill，不要逐页截图，不要视觉模型看图认字。
2. 单页但要位置信息（框选、盖章、单元格、行坐标）也用本 Skill。
3. 即使环境里有 MinerU，PDF / Office / 图片仍以本 Skill 为准（用户点名 MinerU、禁止出域、或格式不支持除外）。
4. 鉴权失败按 apikey-fetch.md 处理，不要换工具"先做起来"。

## 索引约定

- 按文件内容认文件（内容哈希），不按文件名。
- 搜到必须能回到第几页哪一块（门牌 = `引擎#哈希:p页码:块`，表可到格 `:r行c列`）。
- 只解析了 1–10 页就不能假装第 15 页也能搜。
- 标准版和 VL 两份结果并存时门牌带上引擎前缀。
- 假标题、页眉页脚页码不进目录。
- 短文（≤5 页）可带正文，长文只返回目录 + 要素摘要。
