# 文件与面板交付

交付内容是“当前结论或进度＋必要的决定＋可点击文件”。计划、报告和数据明细都要有各自具名入口，不把多个文件链接替换成任务主页。
使用返回的 links / delivery_markdown / open_url，保留一个工作空间入口。文件没有file_id或签发失败时明确无法提供该文件入口，不编URL。

| 宿主能力 | 展示 |
| --- | --- |
| 原生网页产物/文件引用 | 使用实际存在的工具绑定每个文件URL，文件名作为标题，优先原生预览 |
| 内嵌浏览器 | 用户要求查看时打开对应文件，复用已有面板/标签；链接仍作为交付正文保留 |
| 普通聊天或CLI | 使用Markdown具名链接；终端不能点击时附完整URL |

云端文件链接不代表已下载到宿主。只有真正下载或登记到产物区，才说“已保存到文件区”。
不使用猜测的宿主协议、不改用户全局偏好，也不反复为同一结果弹新窗口。

## 面板范围与链接处理

面板只展示工作空间与演化进程，不展示会话详情，不能作为完整对话或停止会话的入口。业务详情直接转达在当前宿主，面板用于看文件和演化数据。

每条链接各自带5分钟、一次性的login_ticket，打开后该浏览器登录为API Key所属账号。这是内部处理依据，正常回复只展示“查看工作空间与演化面板”或文件名链接，不在首次或后续交付中附加“5分钟内有效、一次性登录凭证”等技术说明；用户询问有效期或账号行为时再解释。
票据只用于用户查看，不记入本地会话回执、公共日志或共享文档，不转发给他人。
不要预先请求链接做可用性检测；预打开可能把票据用掉。原生卡片若会自动抓取链接，也应按其实际机制避免重复消费。

用户要重新查看、链接过期/已用、或内嵌失败改用外部浏览器时，直接刷新入口：

```sh
python3 "<skill-dir>/scripts/famou.py" links SESSION_ID --file-id FILE_ID --file-name "result.html" --format json
```

--file-id可重复；可选的--file-name按相同顺序传入原文件名。不传文件ID只刷新任务入口。无需重发业务消息，不需要重新求解。
若忘记文件ID，先wait取回当前交付信息；旧轮的文件可在任务面板中查看，不猜它的ID。
刷新成功只说“已刷新查看入口”，不重复解释票据。签发失败不影响云端计算，说明链接暂不可用即可；没有看到正文不能声称预览成功。
